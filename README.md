# 六六游戏屋

一个适合孩子在浏览器中游玩的小游戏集合。首页以自适应宫格展示已经完成的游戏，可在 PC、iPad 和手机浏览器中访问。

## 已有游戏

- **接星星**：移动篮子接住星星，接住 10 颗就能获胜；漏掉 3 颗后本轮结束。
- **五子棋**：支持人人对战和人机对战，人机模式可选择简单、中等或困难难度。
- **围棋**：支持九路、十三路和十九路棋盘，可与朋友对弈或挑战三种难度的电脑。
- **探索小世界**：在家、学校、医院和超市之间自由探索，点击人物进行交流，并自动保存上次位置。

## 开始游戏

安装依赖并启动 Vite 开发服务器：

```bash
npm ci
npm run dev
```

然后访问命令行提示的本地地址（默认是 <http://127.0.0.1:5173>），从游戏大厅选择想玩的游戏。项目包含浏览器无法直接解析的 npm 模块，因此不要使用简单的 Python 静态服务器运行源码。

## 操作方法

所有游戏共用健康游玩时间：进入任意具体游戏页面且页面可见时会累计时间，游戏大厅和不可见的后台页面不计时。累计游玩 10 分钟后，游戏会保存当前进度并进入 1 小时休息时间；刷新或重新打开游戏仍会显示剩余倒计时。休息结束后点击“继续游戏”，即可恢复之前的进度并开始新一轮游玩时间。

“接星星”支持以下操作：

- 键盘：按 `←`、`→` 移动篮子，按空格键暂停或继续。
- 手机或平板：按住页面下方的左右按钮。
- 点击右上角的声音按钮可以打开或关闭音效。
- 点击游戏页顶部的“游戏大厅”可返回首页。

“五子棋”支持以下操作：

- 选择“人人对战”与身边的朋友轮流落子，或选择“人机对战”挑战电脑。
- 人机对战提供简单、中等、困难三种难度，玩家执黑棋先手。
- 使用鼠标或触摸棋盘交叉点落子；也可使用方向键移动光标，按回车或空格落子。
- 对局中可以悔棋、重新开始或返回模式选择。

“围棋”支持以下操作：

- 选择九路、十三路或十九路棋盘，进行人人对战或人机对战。
- 人机模式提供简单、中等、困难三种难度，玩家执黑棋先手。
- 游戏支持提子、禁自杀和简单劫，使用中国规则数子法，黑棋贴 3¾ 子。
- 双方连续停一手后进入终局确认，可按棋块标记死棋；双方确认后数子，也可以继续对局。

“探索小世界”支持以下操作：

- 点击或触摸场景地面，角色会移动到目标位置。
- 点击或触摸 NPC 才会开始对话，靠近 NPC 不会自动触发。
- 通过地点门口返回世界地图，再选择其他地点。
- 游戏会自动保存在当前浏览器中，下次进入时恢复上次位置。

## 项目结构

```text
index.html                         游戏大厅
assets/css/home.css                大厅布局与响应式样式
assets/images/                     游戏封面资源
games/catch-stars/index.html       “接星星”游戏页面
games/catch-stars/game.css         游戏样式
games/catch-stars/game.js          游戏逻辑
games/gomoku/index.html            “五子棋”游戏页面
games/gomoku/game.css              棋盘与响应式样式
games/gomoku/game.js               页面交互与绘制逻辑
games/gomoku/engine.mjs            五子棋规则与电脑算法
games/go/                           “围棋”页面、规则引擎与电脑算法
games/explore-world/                “探索小世界”游戏、场景数据与素材
.github/workflows/deploy-pages.yml GitHub Pages 发布流程
```

## 添加新游戏

1. 在 `games/` 下为游戏新建独立目录，并把页面、样式和脚本放入该目录。
2. 在 `assets/images/` 中加入比例统一的游戏封面。
3. 在根目录 `index.html` 的 `.game-grid` 中增加游戏卡片，并链接到新游戏页面。
4. 更新首页显示的游戏数量和本 README 的“已有游戏”列表。

## 发布到互联网

项目通过 GitHub Actions 发布到 GitHub Pages。第一次发布前，在仓库 **Settings → Pages** 中将 **Source** 设为 **GitHub Actions**，然后把代码合并或推送到 `main` 分支。之后每次更新 `main` 都会自动重新发布。

## 开发分支

本地开发统一使用 `codex` 分支。首次克隆仓库后可运行：

```bash
git switch -c codex
git push -u origin codex
```

后续提交通过 Pull Request 合并到 `main`，避免直接修改发布分支。
