# 六六游戏屋

一个适合孩子在浏览器中游玩的小游戏集合。首页以自适应宫格展示已经完成的游戏，可在 PC、iPad 和手机浏览器中访问。

## 已有游戏

- **接星星**：移动篮子接住星星，接住 10 颗就能获胜；漏掉 3 颗后本轮结束。
- **五子棋**：支持人人对战和人机对战，人机模式可选择简单、中等或困难难度。
- **围棋**：支持九路、十三路和十九路棋盘，可与朋友对弈或挑战三种难度的电脑。
- **井字棋**：在三乘三棋盘上连成三子，可与朋友对战或挑战三种难度的电脑。
- **国际象棋**：支持完整基础规则，可与朋友对弈或挑战三种难度的电脑。
- **探索小世界**：在原创的温暖像素村庄中探索家、学校、医院和超市，与居民交流，并自动保存上次位置。
- **2048**：滑动并合并数字方块，达到 2048 即获胜；昵称、当前进度和前十名成绩保存在当前浏览器。
- **连连看**：在五分钟内配对清空八乘八棋盘，支持两次转弯路径、提示和自动保存。
- **打砖块**：用键盘、鼠标或触屏控制球拍，拥有三条生命并挑战三个逐步变化的关卡。
- **数独**：提供简单、中等和困难三种唯一解题目，支持候选笔记、撤销、提示和自动保存。
- **华容道**：包含经典“横刀立马”和另外两种可解阵型，支持点击、方向键、拖动和悔步。
- **纸牌接龙**：经典克朗代克摸一张玩法，支持红黑交替叠牌、四个基础牌堆、撤销和自动保存。

## 开始游戏

安装依赖并启动 Vite 开发服务器：

```bash
npm ci
npm run dev
```

然后访问命令行提示的本地地址（默认是 <http://127.0.0.1:5173>），从游戏大厅选择想玩的游戏。项目包含浏览器无法直接解析的 npm 模块，因此不要使用简单的 Python 静态服务器运行源码。

## 操作方法

所有游戏共用健康游玩时间：进入任意具体游戏页面且页面可见时会累计时间，游戏大厅和不可见的后台页面不计时。同一浏览器同时打开多个游戏页面时，只有负责计时的页面可以操作；其他页面会提示切回该页面。计时页面关闭后，其他页面需要刷新以载入最新进度。累计游玩 15 分钟后，游戏会保存当前进度并进入 30 分钟休息时间；刷新或重新打开游戏仍会显示剩余倒计时。休息结束后点击“继续游戏”，即可恢复之前的进度并开始新一轮游玩时间。

“接星星”支持以下操作：

- 键盘：按 `←`、`→` 移动篮子，按空格键暂停或继续。
- 手机或平板：按住页面下方的左右按钮。
- 点击右上角的声音按钮可以打开或关闭音效。
- 点击游戏页顶部的“游戏大厅”可返回首页。

“五子棋”支持以下操作：

- 选择“人人对战”与身边的朋友轮流落子，或选择“人机对战”挑战电脑。
- 人机对战提供简单、中等、困难三种难度，玩家执黑棋先手。
- 使用鼠标或触摸棋盘交叉点落子；也可使用方向键移动光标，按回车或空格落子。
- 对局中可以悔棋、重新开始或返回模式选择。

“围棋”支持以下操作：

- 选择九路、十三路或十九路棋盘，进行人人对战或人机对战。
- 人机模式提供简单、中等、困难三种难度，玩家执黑棋先手。
- 游戏支持提子、禁自杀和简单劫，使用中国规则数子法，白棋贴 7.5 目；双方连续停一手后进入终局确认，系统可标出候选死棋，但仍需双方检查和确认。
- 双方连续停一手后进入终局确认，可按棋块标记死棋；双方确认后数子，也可以继续对局。

“井字棋”支持以下操作：

- 选择“人人对战”或“人机对战”，人机模式提供简单、中等、困难三种难度。
- 点击棋盘格落子；也可使用方向键移动光标，按回车或空格落子。
- 对局中可以悔棋、重新开始或返回模式选择；人机模式会撤销最近一整回合。

“国际象棋”支持以下操作：

- 选择“人人对战”或“人机对战”，人机模式提供简单、中等、困难三种难度，玩家执白先手。
- 点击棋子后再点击目标格走棋；也可使用方向键移动光标，按回车或空格选择棋子或落子。
- 支持将军、将死、逼和、王车易位、吃过路兵和兵升变；兵走到底线时可选择升变为后、车、象或马。
- 同一局面第三次出现，或连续 100 个半回合（双方各 50 回合）没有兵移动和吃子时自动判和；双人对战中也可由一方求和、另一方同意和棋。
- 对局中可以悔棋、重新开始或返回模式选择；人机模式会撤销最近一整回合。

“探索小世界”支持以下操作：

- 使用方向键或 `WASD` 移动，也可点击或触摸场景地面前往目标位置。
- 在世界地图上可用方向键选择地点、按回车或空格进入；场景内可按 `E` 与附近的人物或门互动。
- 点击或触摸 NPC 才会开始对话，靠近 NPC 不会自动触发。
- 通过地点门口返回世界地图，再选择其他地点。
- 游戏会自动保存在当前浏览器中，下次进入时恢复上次位置。

“2048”支持以下操作：

- 首次游玩需要设置昵称；可使用方向键或 `WASD` 移动方块，也可在手机或平板上滑动棋盘。
- 两个相同数字相撞时合并；达到 2048 即立即获胜并结束本局，没有可用移动时本局结束。
- 当前局面和本地前十名排行榜会自动保存在当前浏览器，不会上传或跨设备同步；刷新页面可继续当前对局。

“连连看”支持以下操作：

- 在五分钟内清空八乘八棋盘；点击两张相同图案进行配对，连线路径不能穿过其他图案，最多转弯两次，也可以绕过棋盘外围。
- 可使用三次提示，点击“洗牌”重新排列剩余图案；若当前没有可配对的组合，游戏会自动洗牌。
- 可使用鼠标或触摸点击图案，也可聚焦棋盘后用方向键移动、按回车或空格选择；按 `Esc` 或点击“暂停”可暂停计时。
- 当前棋盘和剩余时间保存在当前浏览器中；刷新页面会恢复本局。页面切换到后台或进入休息倒计时期间，关卡计时暂停。

“打砖块”支持以下操作：

- 按 `←`、`→` 或 `A`、`D` 移动球拍，按空格键发球或暂停；鼠标、触屏可直接拖动球拍。
- 每局有三条生命、三个关卡；清除当前关卡砖块后可进入下一关，进度会自动保存在当前浏览器。

“数独”支持以下操作：

- 选择简单、中等或困难题目；使用键盘 `1` 到 `9`、页面数字键盘或移动端触控填写数字。
- 点击“笔记”可记录候选数字，支持擦除、撤销和每局三次提示；题目均为随机生成且保证唯一解。
- 刷新页面可恢复当前题目与进度；切换难度或点击“新题”会开始新的随机题目。

“华容道”支持以下操作：

- 挑战经典“横刀立马”及另外两种阵型，点击棋子后用方向按钮或键盘方向键移动，也可在棋子上拖动。
- 每次滑动一格计为一步；可撤销上一步、重开当前阵型，通关后进入下一关。棋盘进度保存在当前浏览器。

“纸牌接龙”支持以下操作：

- 本游戏采用克朗代克“摸一张”规则：点击左上方牌堆翻牌，按红黑交替、数字递减将牌叠入七列。
- 点击一张牌后再点击目标列或基础牌堆即可移动；桌面端也可拖动纸牌，双击单张牌可尝试移入基础牌堆。
- 将 A 到 K 按同一花色整理到四个基础牌堆即可获胜；支持撤销、新局和当前浏览器自动存档。


## 添加新游戏

1. 在 `games/` 下为游戏新建独立目录，并把页面、样式和脚本放入该目录。
2. 在 `assets/images/` 中加入比例统一的游戏封面。
3. 在根目录 `index.html` 的 `.game-grid` 中增加游戏卡片，并链接到新游戏页面。
4. 更新首页显示的游戏数量和本 README 的“已有游戏”列表。

## 发布到互联网

项目通过 GitHub Actions 发布到 GitHub Pages。第一次发布前，在仓库 **Settings → Pages** 中将 **Source** 设为 **GitHub Actions**，然后把代码合并或推送到 `main` 分支。之后每次更新 `main` 都会自动重新发布。

## 开发分支

本地开发统一使用 `codex` 分支。首次克隆仓库后可运行：

```bash
git switch -c codex
git push -u origin codex
```

后续提交通过 Pull Request 合并到 `main`，避免直接修改发布分支。
